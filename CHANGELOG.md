# Changelog

All notable changes to this repository's documentation and examples are listed here.

## 2026-10-10

First public release of the Writ for websites documentation and examples.

- Guides: quickstart, how it works, shipping workflows (bundled, linked, settings, credentials,
  private recipes, updates), security for integrators (receipts, device pinning, enrolling
  computers), what users see, troubleshooting.
- The public wire contract (`docs/contract.md`), protocol 1.
- Examples: a static page with the `@usewrit/web` script tag, a Node (Express) server with
  `@usewrit/server`, and a Python (FastAPI) server with `usewrit`.
- Covers `@usewrit/web` 0.2.0, `@usewrit/server` 0.1.0, `usewrit` 0.1.0 and Writ desktop 1.0.8.
